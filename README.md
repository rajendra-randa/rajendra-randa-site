# Rajendra Randa — Researcher Portfolio

Personalized Next.js + TypeScript academic portfolio based on the supplied profile and publication information.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Important customization

Replace `public/resume.pdf` with the actual CV PDF.

Replace the placeholder initials block with a real profile photo later if desired.

Publication data is in `app/page.tsx` and is intentionally data-driven so additional records can be added without changing the UI.

## Sections

- Home / authored quote
- Basic Information
- Academic qualifications
- Technical skills
- Teaching philosophy
- Research & Publications
- Journal publications
- Conference proceedings
- Conference presentations
- Book chapters
- Patents
- Research areas
- Work & contributions
- Memberships
- Training highlights

The visual language is Elsevier-inspired rather than a direct copy of Elsevier's proprietary website/branding.
